Looking up a value

What does this code print?

d = {"a": 1, "b": 2}
print(d["b"])
  • b
  • 2
  • 1
  • KeyError

The key "b" is used to look up its value, 2.

Missing key

What happens when you run this code?

d = {"a": 1}
print(d["c"])
  • It prints 0.
  • Nothing, the line is skipped.
  • KeyError
  • It prints c.

The dictionary has no key "c". You may check first with if "c" in d:.

Changing and adding

What does this code print?

d = {"a": 1}
d["a"] = 5
d["b"] = 2
print(d)
  • {'a': 5, 'b': 2}
  • {'a': 1, 'b': 2}
  • {'a': 1, 'a': 5, 'b': 2}
  • KeyError

Assigning to an existing key changes its value; assigning to a new key adds an entry. Keys are unique.

Length

What does this code print?

print(len({"x": 10, "y": 20, "z": 30}))
  • 6
  • 3
  • 60
  • 2

len counts the entries (key: value pairs).

The in operator

What does this code print?

ages = {"Ann": 31, "Bob": 25}
print(25 in ages)
  • True
  • Bob
  • False
  • KeyError

in checks the keys, not the values. "Bob" in ages would be True.

Looping with items

What does this code print?

for k, v in {"a": 1, "b": 2}.items():
    print(k, v)
  • a, then b
  • 1, then 2
  • ValueError
  • a 1, then b 2

.items() gives the key and the value together, so the loop has two variables.

List of dictionaries

What does this code print?

movies = [
    {"title": "Up", "rating": 8},
    {"title": "Cats", "rating": 2},
]
print(movies[1]["title"])
  • Cats
  • Up
  • 2
  • KeyError

movies[1] is the second dictionary in the list (counting from 0), and ["title"] looks up its title.

Why dictionaries?

Why use a dictionary instead of two lists (one for the keys, one for the values)?

  • Lists cannot contain strings.
  • A dictionary finds a value in a single step, no matter how large it is.
  • With two lists it is impossible to find a value.
  • A dictionary keeps its keys in alphabetical order.

With two lists you have to check the keys one by one, which is slow for large data. A dictionary looks up a key directly.
