Accessing elements

What does this code display?

l = [5, 10, 15, 20]
print(l[1], l[-1])
  • 5 20
  • 10 20
  • 5 15
  • 10 15

Indexing starts from 0, and -1 is the last element.

Slicing

What does this code display?

l = [5, 10, 15, 20]
print(l[1:3])
  • [10, 15]
  • [5, 10, 15]
  • [10, 15, 20]
  • [15]

The first number is the first index included, the second is the first index excluded.

List in a list

What does this code display?

l = [1, [2, 3], 4]
print(l[1][0])
  • 1
  • [2, 3]
  • 3
  • 2

l[1] is the inner list [2, 3], and [0] then selects its first element.

Useful functions

What does this code display?

grades = [2, 4, 6]
print(sum(grades)/len(grades))
  • 12
  • 4.0
  • 3
  • 2.0

sum gives 12 and len gives 3. Division / always gives a float.

sort and sorted

What does this code display?

nums = [3, 1, 2]
new_nums = sorted(nums)
print(nums, new_nums)
  • [1, 2, 3] [1, 2, 3]
  • [3, 1, 2] [3, 1, 2]
  • [3, 1, 2] [1, 2, 3]
  • [1, 2, 3] [3, 1, 2]

sorted() returns a new list and leaves the original untouched. .sort() would change nums in-place.

Mutable and immutable

l is a list and s is a string. Which of these work? Select all that apply, then press Check.

  • l[0] = "x"
  • s[0] = "x"
  • l.append("x")
  • s.append("x")

Lists are mutable, so they can be changed in place. Strings are immutable: s[0] = "x" gives a TypeError, and strings have no .append() method.

Checking contents

What does this code display?

my_pets = ["parrot", "frog"]
print("cat" in my_pets, "frog" in my_pets)
  • True True
  • True False
  • False False
  • False True

The in operator checks if the list contains an element.

for loop

What does this code display?

titles = []
for book in ["ab (1)", "cd (2)"]:
    titles.append(book[:2])
print(titles)
  • ['ab', 'cd']
  • ['cd']
  • ['ab (1)', 'cd (2)']
  • ab, then cd

The body of the loop runs for every element, and adds its first two characters to the list. The print is not indented, so it runs once, after the loop.
