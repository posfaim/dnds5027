Integer division

What does print(7 // 2, 7 % 2) display?

  • 3.5 1
  • 3 1
  • 1 3
  • 3 0.5

// is the integer part of a division (7 / 2 is 3.5, so 3), and % is the remainder (7 = 2 * 3 + 1, so 1).

Repeating strings

What does print("ha" * 3) display?

  • hahaha
  • ha ha ha
  • ha3
  • TypeError

* with a whole number repeats a string, without adding spaces.

Order of operations

What does print(2 + 3 * 4) display?

  • 20
  • 14
  • 24
  • 2 + 3 * 4

Multiplication comes first: 3 * 4 is 12, then 2 + 12 is 14.

Division

What is the type of 10 / 2?

  • int
  • float
  • str

Division / always gives a float: the result is 5.0.

Changing variables

x = 4
x *= 3
x -= 2

What is the value of x after these three lines?

  • 12
  • 2
  • 10
  • 7

x *= 3 makes x 12, then x -= 2 makes it 10.

Variable names

Which of these are allowed variable names? Select all that apply, then press Check.

  • my_name
  • 2nd_place
  • first-name
  • Total

Names may only contain letters, digits and underscores, and cannot start with a digit. 2nd_place starts with a digit, and first-name contains a -. Total is allowed, but not recommended, because it is not snake case (lowercase words joined by underscores): total is better.

Strings and numbers

Why does print("5" + 3) fail?

  • You cannot add a string and a number (TypeError).
  • A quotation mark is missing (SyntaxError).
  • It does not fail: it prints 8.
  • It does not fail: it prints 53.

"5" is a string (it is in quotes) and 3 is a number. + cannot combine the two, so Python gives a TypeError.

Type conversion

Which line prints the number 8?

  • print(int("5") + 3)
  • print("5" + "3")
  • print(int("5" + 3))
  • print(5 + "3")

int("5") converts the string to the number 5, then 5 + 3 is 8. "5" + "3" joins two strings and prints 53; the other two give a TypeError.
