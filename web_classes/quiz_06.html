While loop

How many lines does this code print?

num = 1
while num < 5:
    print(num)
    num += 1
  • 5
  • 4
  • 6
  • It never stops.

num takes the values 1, 2, 3 and 4. When it reaches 5, num < 5 is False and the loop stops.

While loop again

What happens when you run this code?

num = 1
while num <= 10:
    print(num)
    num -= 1
  • It prints the numbers 1 to 10.
  • It prints nothing.
  • It starts counting down and never stops (infinite loop).
  • SyntaxError

num goes down (1, 0, -1, ...), so num <= 10 is always True. In Jupyter, stop it with the ■ button.

Break

What does break do inside a loop?

  • It leaves the loop immediately.
  • It skips to the next round of the loop.
  • It stops the whole program.
  • It starts the loop again from the beginning.

After break, the program continues with the first line after the loop.

Range

Which numbers does this code print?

for i in range(2, 5):
    print(i)
  • 2, 3, 4, 5
  • 2, 3, 4
  • 3, 4, 5
  • 0, 1, 2, 3, 4

Like slicing: the start (2) is included and the stop (5) is excluded.

Adding up

What does this code print?

total = 0
for n in [3, 5, 2]:
    total += n
print(total)
  • 0
  • 2
  • 352
  • 10

total is a helper variable: it becomes 3, then 8, then 10.

Looping over a string

What does this code print?

for c in "hey":
    print(c)
  • h, e and y, each on its own line
  • hey
  • h e y on one line
  • An error: you cannot loop over a string.

A string serves up its characters one by one, and each print starts a new line.

Nested loops

How many lines does this code print?

for i in range(3):
    for j in range(2):
        print(i, j)
  • 5
  • 6
  • 3
  • 9

The inner loop runs completely (2 rounds) for each of the 3 rounds of the outer loop: 3 × 2 = 6.

Indentation

How many times is done printed?

for i in range(3):
    print(i)
print("done")
  • 3
  • 0
  • 1
  • 4

print("done") is not indented, so it is not part of the loop: it runs once, after the loop.

Buggy maximum

We intend to find the maximum number from the list below. What does the code print?

nums = [-5, -2, -9]
m = 0
for num in nums:
    if m < num:
        m = num
print(m)
  • -2
  • -5
  • 0
  • -9

No number in the list is larger than 0, so m stays 0. Starting with m = nums[0] would give the correct maximum, -2.
