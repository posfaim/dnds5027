Tuples and lists

What does this code display?

t = (1, 2, 3, 4)
print(t[1:3])
  • [2, 3]
  • (2, 3)
  • (1, 2, 3)
  • (2, 3, 4)

Slicing works the same way as for lists. Slicing a tuple gives a tuple, so the result is in round brackets.

Immutable

t is the tuple (1, 2, 3). Which of these work? Select all that apply, then press Check.

  • t[0]
  • len(t)
  • t[0] = 5
  • t.append(4)

You can read the elements and the length of a tuple. Tuples are immutable: t[0] = 5 gives a TypeError, and tuples have no .append() method.

Dictionary keys

Which of these can be a key in a dictionary? Select all that apply, then press Check.

  • "Paris"
  • ("London", "Paris")
  • ["London", "Paris"]
  • 42

Keys must be immutable. Strings, numbers and tuples are fine. A list is mutable, so it gives TypeError: unhashable type: 'list'.

Implicit tuples

What does this notebook cell display?

x = 10
y = 2*x
x, y
  • 10 20
  • 20
  • (10, 20)
  • [10, 20]

x, y creates a tuple, even without (). The notebook displays the tuple, with round brackets.

Unpacking

What does this code display?

a, b = (3, 7)
print(b)
  • (3, 7)
  • 3
  • An error message
  • 7

Unpacking assigns the elements of the tuple to the variables in order: a is 3 and b is 7.

Returning multiple values

What does this code display?

def min_and_max(L):
    return min(L), max(L)

low, high = min_and_max([4, 1, 9])
print(high - low)
  • 8
  • 5
  • (1, 9)
  • An error message

The function returns the tuple (1, 9), which gets unpacked: low is 1 and high is 9.

Swapping

What does this code display?

a = 10
b = 5
a = b
b = a
print(a, b)
  • 5 10
  • 5 5
  • 10 10
  • 10 5

After a = b, both are 5, and the old value of a is lost. To swap, write a, b = b, a.

Dictionary items

What does this code display?

d = {"King": 13.5, "Adelie": 4.5}
for t in d.items():
    print(t)
  • King
Adelie
  • 13.5
4.5
  • ('King', 13.5)
('Adelie', 4.5)
  • King 13.5
Adelie 4.5

.items() gives each key and value together as a tuple. With two loop variables, for key, value in d.items():, the tuple gets unpacked.

zip

What does this code display?

names = ["Ann", "Bob"]
ages = [30, 25]
for name, age in zip(names, ages):
    print(name, age)
  • Ann Bob
30 25
  • Ann 30
  • ('Ann', 'Bob')
(30, 25)
  • Ann 30
Bob 25

zip pairs up the elements of the two lists: first with first, second with second. The loop unpacks each pair into name and age.
