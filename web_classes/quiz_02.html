Comparisons

What does print(3 >= 3, 4 != 4) display?

  • False False
  • True True
  • True False
  • False True

3 >= 3 means "greater or equal", which is True. 4 != 4 means "not equal", which is False.

= and ==

What is the difference between x = 5 and x == 5?

  • There is no difference.
  • x = 5 stores 5 in x; x == 5 checks if x is equal to 5.
  • x = 5 checks if x is equal to 5; x == 5 stores 5 in x.
  • x == 5 stores 5 in x twice.

= is the assignment operator. == is a comparison, and its result is True or False.

Combining conditions

What does this code display?

print(5 > 2 and 1 > 3)
print(5 > 2 or 1 > 3)
  • False, then True
  • True, then False
  • True, then True
  • False, then False

5 > 2 is True and 1 > 3 is False. and needs both sides to be True; or needs at least one.

not

Which condition always gives the same result as not (x > 4)?

  • x > 4
  • x < 4
  • x != 4
  • x <= 4

If x is not greater than 4, it is less than or equal to 4. Do not forget the case x = 4: x < 4 would be False there, but not (x > 4) is True.

Blocks

What does this code display?

num = -2
if num > 0:
    print("positive")
print("done")
  • positive, then done
  • only done
  • only positive
  • nothing

The condition is False, so the indented line is skipped. The last line is not indented, so it is not part of the block and always runs.

elif

What does this code display?

score = 95
if score > 50:
    print("pass")
elif score > 90:
    print("excellent")
else:
    print("fail")
  • pass
  • excellent
  • pass, then excellent
  • fail

The conditions are checked from top to bottom, and only the block of the first True condition runs. score > 50 is already True, so elif is never checked.

Indentation

What happens when you run this code?

num = 4
if num > 0:
    print(num, "is positive.")
   print("And I am happy about this.")
  • It prints both messages.
  • It prints only the first message.
  • Python stops with an IndentationError.
  • Python stops with a TypeError.

The last line is indented by 3 spaces, while the line before it has 4. The indentation within a block must be consistent.

Comparing strings

Which of these are True? Select all that apply, then press Check.

  • "Hungary" == "Hungary"
  • "Hungary" == "hungary"
  • "Hungary" != "Hungry"
  • "Hungary" == "Hungary "

Two strings are equal only if they are exactly the same. Comparisons are case sensitive, and even an extra space at the end makes a difference.

Nested if statements

What does this code display?

country = "Austria"
age = 15
if country == "Austria":
    if age >= 16:
        print("You can vote.")
    else:
        print("You can't vote.")
else:
    print("Unknown country.")
  • You can vote.
  • You can't vote.
  • Unknown country.
  • You can't vote., then Unknown country.

The outer condition is True, so Python enters that block. There age >= 16 is False, so the inner else runs. The outer else belongs to the first if, so it is skipped.
