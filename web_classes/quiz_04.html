Indexing

What does this code display?

s = "Python"
print(s[1])
  • P
  • y
  • t
  • Py

Indexing starts from 0, so s[0] is P and s[1] is y.

Negative indices

What does this code display?

s = "Python"
print(s[-2])
  • n
  • t
  • o
  • h

s[-1] is the last character, n, so s[-2] is o.

Slicing

What does this code display?

s = "The five boxing wizards jump quickly."
print(s[4:6])
  • fi
  • fiv
  • iv
  • f

The first number is the first index included, the second is the first index excluded. So this gives the characters at indices 4 and 5.

Counting

What does print("Dodo bird".count("d")) display?

  • 3
  • 2
  • 1
  • 0

Strings are case sensitive: the capital D does not count, so only the two lowercase d-s do.

New strings

What does this code display?

s = "cat"
s.replace("c", "b")
print(s)
  • cat
  • bat
  • b
  • An error message

.replace() returns a new string and leaves the original unchanged. To keep the change, write s = s.replace("c", "b").

Chaining methods

What does this code display?

s = "one-two"
print(s.replace("-", " ").capitalize())
  • one two
  • One-two
  • ONE TWO
  • One two

The methods run from left to right: .replace() gives "one two", then .capitalize() works on that new string.

Length and index

What does this code display?

s = "Ada"
print(s[len(s)])
  • a
  • 3
  • Ada
  • An error message

len(s) is 3, but indexing starts from 0, so the last index is 2. s[3] gives an IndexError. Use s[-1] for the last character.

f-strings

What does this code display?

num = 2
pi = 3.14159
print(f"{num} and {pi:.2f}")
  • {num} and {pi:.2f}
  • 2 and 3.14
  • 2 and 3.14159
  • 2 and 3.141

Values in curly brackets get inserted into the string, and :.2f displays the float with 2 digits.

Line breaks

Which of these define a string with a line break in it? Select all that apply, then press Check.

  • "one two"
  • "one\ntwo"
  • """one
    two"""
  • "one\\ntwo"

\n is the escape sequence for a line break, and triple quotation marks allow line breaks inside. In the last option, \\ is an actual backslash, so it is followed by a plain letter n.
