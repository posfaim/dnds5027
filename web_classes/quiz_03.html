Defining and calling

What does this code display?

def greet():
    print("Hi!")
    print("Hi!")
  • Hi!, twice
  • greet
  • An error message
  • Nothing

def only defines the function. Its code runs when you call it, with greet().

Printing and returning

What does this code display?

def double_print(x):
    print(2*x)

d = double_print(3)
print(d)
  • 6
6
  • 6
None
  • None
6
  • 6

Calling the function displays 6. It has no return value, so d is None. To use the result later, the function should return it.

Return value

What does this code display?

def add2(a, b):
    return a + b

print(add2(add2(1, 2), 3))
  • 3
  • 5
  • 6
  • 1 2 3

The inner call returns 3, then add2(3, 3) returns 6. You can use the return value of a function as an argument of another.

Multiple returns

What does this code display?

def describe(x):
    if x < 0:
        return "negative"
    return "not negative"
    print("Done.")

print(describe(-5))
  • negative
  • Done.
negative
  • negative
Done.
  • negative
not negative

A function stops at the first return it reaches. With -5 that is return "negative", so the lines below it never run. print("Done.") comes after the last return, so it never runs, whatever the input.

Keyword arguments

What does this code display?

def subtract(a, b):
    return a - b

print(subtract(b=1, a=5))
  • 4
  • -4
  • 1
  • An error message

With keywords the order does not matter: a is 5 and b is 1, so the result is 5 - 1.

Mixing arguments

The function check_divider has three parameters: check_total, tip_percentage and num_people. Which call is **not** allowed?

  • check_divider(10, .2, 2)
  • check_divider(num_people=2, check_total=10, tip_percentage=.2)
  • check_divider(check_total=10, .2, 2)
  • check_divider(10, num_people=2, tip_percentage=.2)

Once you switched to keywords, you cannot go back to positional arguments: this gives a SyntaxError.

Local variables

What happens when you run this code?

def add_one(x):
    result = x + 1
    return result

add_one(1)
print(result)
  • It prints 2.
  • Python stops with a NameError.
  • It prints result.
  • It prints None.

result is a local variable: it exists only while the function runs. To use the value, save it: r = add_one(1).

Same name

What does this code display?

name = "Vera"

def greet(name):
    print("Hello", name)

greet("Ilka")
  • Hello Vera
  • Hello name
  • Hello Vera Ilka
  • Hello Ilka

Python first looks for a local variable. The parameter name is local, and its value in this call is "Ilka".

Modules

Which of these work? Select all that apply, then press Check.

  • import math
print(math.sqrt(4))
  • import math
print(sqrt(4))
  • import math as ma
print(ma.sqrt(4))
  • from math import sqrt
print(sqrt(4))

After import math, you must write math.sqrt; sqrt alone gives a NameError. import math as ma introduces an abbreviation, and from math import sqrt lets you use the name directly.
