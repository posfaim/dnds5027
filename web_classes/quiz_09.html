Reading twice

What does this code display?

f = open('example.csv')
first = f.read()
second = f.read()
print(len(second))
  • The same number as len(first)
  • An error message
  • 0
  • 1

The file handle keeps track of where it is in the file. After the first .read() it is at the end, so the second one gives an empty string. To read the file again, open it again.

One line

The file example.csv contains:

Name,Height
Adam,180
Belzebub,220
Papa Smurf,10

What does the notebook display?

with open('example.csv') as f:
    line = f.readline()
line
  • 'Name,Height'
  • 'Name,Height\n'
  • ['Name', 'Height']
  • 'Name'

.readline() reads one line, including the line break \n at its end.

Line by line

The file names.txt has two lines: Ann and Bob. What does this code display?

with open('names.txt') as f:
    for line in f:
        print(line)
  • Ann
Bob
  • AnnBob
  • Ann

Bob

  • Ann Bob

Each line of the file ends with \n, and print adds another line break, so an empty line appears after each name. print(line, end='') avoids this.

The with block

What happens when you run this code?

with open('example.csv') as f:
    first = f.readline()
second = f.readline()
  • second is 'Adam,180\n'
  • second is 'Name,Height\n'
  • second is ''
  • Python stops with an error message

Python closes the file when the with block ends. Reading a closed file gives ValueError: I/O operation on closed file.

Splitting a row

What does this code display?

row = "Paris,2024\n"
print(row.split(','))
  • ['Paris', '2024\n']
  • ['Paris', '2024']
  • ['Paris,2024\n']
  • ['Paris', ',', '2024\n']

.split(',') cuts the string at the commas and leaves out the commas. The line break stays at the end of the last entry. row.strip().split(',') removes it first.

Parsing

The file example.csv contains:

Name,Height
Adam,180
Belzebub,220
Papa Smurf,10

What does this code display?

total = 0
with open('example.csv') as f:
    f.readline()
    for line in f:
        total += float(line.split(',')[1])
print(total)
  • 230.0
  • 410.0
  • 410
  • An error message

f.readline() reads the header, so the loop starts at Adam and adds 180 + 220 + 10. float makes the result a float. Without skipping the header, float('Height\n') would give an error.

Writing twice

What does this code display?

with open('log.txt', 'w') as f:
    f.write('one\n')
with open('log.txt', 'w') as f:
    f.write('two\n')
with open('log.txt') as f:
    print(f.read())
  • two
  • one
two
  • one
  • two
one

'w' overwrites the file, so the first line is lost. To add to the end of the file, open it with 'a'.

Writing lines

What does the file out.txt contain after this code?

with open('out.txt', 'w') as f:
    for name in ['Ann', 'Bob']:
        f.write(name)
  • Ann
Bob
  • Ann Bob
  • ['Ann', 'Bob']
  • AnnBob

.write() writes exactly the string it gets, without a line break. Write f.write(name + '\n') to put each name on its own line.

Strange characters

You open a csv file and see JosÃ© instead of José. What is the most likely cause?

  • The file is a binary file, not a text file.
  • The name is misspelled in the file.
  • The file was saved as UTF-8, but opened with a different encoding.
  • The file was not closed.

Accented letters are stored differently in each encoding. A UTF-8 file opened with an older encoding, such as 'cp1252' on Windows, turns each accented letter into two strange characters. Open it with encoding='utf-8'.
