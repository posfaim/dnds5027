Strings

  • A string represents text. Write it between quotation marks: "Ernie" or 'Bert', but don’t mix the two.
  • What we already did with strings:
print("CEU"+" PU")        # concatenate
print("he"*5)             # repeat
print("Ernie"=="Bert")    # compare
print(str(7)+" dwarfs")   # convert to a string
print(int("41")+1)        # convert from a string

Accessing characters

  • len returns the number of characters, including spaces and punctuation.
s = "Bird is the word."
print(len(s))
17
  • A string is a sequence of characters, and each character has an index. Indexing starts from 0.

  • The square brackets [] look up the character at an index. An index out of range gives an IndexError. As always, read error messages carefully, starting at the bottom.
print(s[10])
print(s[19])
e
IndexError: string index out of range
  • You can also count from the back with negative indices:

print(s[-1], s[-11])

Slicing

  • [] can also access substrings. The first number is the first index included, the second is the first index excluded.

  • Leave out the first number to start at the beginning, or the second to go to the end.
print(s[5:11])
print(s[:5])

Methods

  • Methods are functions that are bound to an object. Write the object’s name, a dot . and the name of the method, then the arguments in parentheses. The method always has access to its object, so you don’t pass it as an argument.
nice_string = "Dodo bird"
num_ds = nice_string.count("d")
print(num_ds)
2

  • Strings come with many methods, for example:
print("  void  ".strip())                          # remove whitespaces at both ends
print("I am a dog person.".replace("dog", "cat"))  # takes 2 arguments
print("nemecsek".capitalize())                     # takes no arguments
print("educated cat".find("cat"))                  # index of the first occurrence
print("educated cat".find("dog"))                  # -1 if not found

Changing a string

  • A method like .replace() creates a new string. The original stays unchanged:
s = "Vera is four years old."
new_s = s.replace("four", "five")
print("Original:", s)
print("New:", new_s)
Original: Vera is four years old.
New: Vera is five years old.
  • To change the original, overwrite it. You can make several changes in one line by chaining the methods:
s = "Vera is four years old."
s = s.replace("four", "five").replace(".", "!")
print(s)
Vera is five years old!

f-strings

  • Building messages with + and str() is cumbersome and difficult to read:
num_diners = 7
num_pizzas = 12
message = "The " + str(num_diners) + " diners get "
message += str(num_pizzas/num_diners) + " pizzas each."
print(message)
The 7 diners get 1.7142857142857142 pizzas each.
  • An f-string is prepended with the letter f, and can include variables and expressions in curly brackets {}. Formatting options can set, for example, the number of digits of a float (more options).
print(f"The {num_diners} diners get {num_pizzas/num_diners} pizzas each.")
print(f"The {num_diners} diners get {num_pizzas/num_diners:.3f} pizzas each.")
The 7 diners get 1.7142857142857142 pizzas each.
The 7 diners get 1.714 pizzas each.

Escape sequences

  • Pressing enter inside a string gives an error, since it starts a new line in the code:
s = "Do I contradict myself?
Very well then I contradict myself,"
SyntaxError: unterminated string literal (detected at line 1)
  • The backslash \ gives the next character a special meaning. This is an escape sequence: \n is a line break, \t is a tab, \" is a quotation mark and \\ is an actual backslash.
print("Do I contradict myself?\nVery well then I contradict myself,")
Do I contradict myself?
Very well then I contradict myself,
  • Triple quotation marks """ define a multi-line string, which allows line breaks inside:
poem = """There was an old person of Minety
Who purchased five hundred and ninety"""
print(poem)
There was an old person of Minety
Who purchased five hundred and ninety

Common mistakes

  • Index off by one: the last index of a string is its length minus 1, so s[len(s)] gives an IndexError. Use s[-1] for the last character.
  • Expecting the end of a slice to be included: s[5:11] stops at index 10.
  • Not saving the result of a string method: s.replace("four", "five") on its own line leaves s as it was. Write s = s.replace("four", "five").
  • replace and find also match inside words: "educated cat".replace("cat", "dog") gives "edudoged dog". There is no error, so check the result.
  • Case sensitivity: "Dodo bird".count("d") is 2, since the capital D does not count.
